# Programming Fundamentals – oefeningen

Mijn oplossingen voor de oefeningen van het vak **Programming Fundamentals** (Graduaat Programmeren, Erasmushogeschool Brussel), geschreven in JavaScript en uitgevoerd met Node.js.

## Oefeningen

| Bestand | Wat het doet | Concepten |
|---|---|---|
| `e1_beginnen.mjs` | Toont een begroeting met mijn naam, leeftijd en lievelingsgame | variabelen, strings samenvoegen |
| `e2_dynamisch.mjs` | Vraagt naam, leeftijd en lievelingsgame aan de gebruiker en toont een begroeting | gebruikersinvoer met `readline` |
| `e3_opteller.mjs` | Telt twee ingevoerde getallen op | `parseFloat`, rekenen |
| `opteller.mjs` | Rekenmachine: som, verschil, product en deling van twee getallen | rekenkundige operatoren |
| `leeftijd.mjs` | Berekent hoe oud je bent in 2031 op basis van je geboortejaar | invoer, berekeningen |
| `arrays_loop.mjs` | Drukt alle elementen van een array af | arrays, `for`-loop |

## Uitvoeren

Installeer [Node.js](https://nodejs.org/) (versie 18 of hoger, nodig voor `await` buiten een functie) en voer een oefening uit met:

```bash
node e2_dynamisch.mjs
```
